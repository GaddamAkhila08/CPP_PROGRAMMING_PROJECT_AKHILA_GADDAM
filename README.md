## 📌 Project Overview

The **Custom String Class Management System** is a C++ menu-driven application that implements a user-defined string class similar to the C++ Standard Template Library (`std::string`). This project demonstrates the practical implementation of Object-Oriented Programming (OOP) concepts, including dynamic memory allocation, constructors, destructors, copy constructors, operator overloading, and string manipulation.

The application provides an interactive console-based interface where users can perform various string operations efficiently without using the built-in `std::string` class.

---

## ✨ Features

- Menu-Driven User Interface
- Enter and Store a New String
- Display Current String
- Find String Length
- Append Another String
- Compare Two Strings
- Search for a Substring
- Extract a Substring
- Clear the Current String
- Check Whether the String is Empty
- Concatenate Two Strings using `+`
- Equality Comparison using `==`
- Character Access using `[]`
- Dynamic Memory Management
- Operator Overloading
- Modular Programming using Header and Source Files
