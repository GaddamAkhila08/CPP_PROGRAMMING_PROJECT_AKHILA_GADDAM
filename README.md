# Custom String Class Management System (STL::string Clone)

## Author
**Name:** Akhila Gaddam

---

## Project Overview

This project is a custom implementation of the C++ Standard Template Library (STL) `string` class. It demonstrates Object-Oriented Programming (OOP) concepts such as dynamic memory allocation, constructors, destructors, copy constructors, operator overloading, and string manipulation by creating a user-defined string class.

The project provides a **menu-driven interface** that allows users to perform various string operations interactively.

---

## Features

- Default Constructor
- Parameterized Constructor
- Copy Constructor
- Destructor
- Assignment Operator
- Enter New String
- Display Current String
- Find String Length
- Append Another String
- Compare Two Strings
- Search Substring
- Extract Substring
- Clear Current String
- Check if String is Empty
- Concatenate Two Strings using `+`
- Equality Comparison using `==`
- Character Access using `[]`
- Menu-Driven Interface
